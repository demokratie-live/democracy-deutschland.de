# Abweichungen vom Original

Die statische Seite ist ein 1:1-Port von [democracy-deutschland.de](https://democracy-deutschland.de/). Hier steht jede bewusste Abweichung und jeder behobene Fehler mit Begründung, außerdem die Restabweichungen aus dem Screenshot-Vergleich (`pnpm compare`). Maßstab ist die Live-Seite, nicht das PHP-Repo.

## Rahmen und Technik

| Thema                                                | Live                                                                                                | Statische Seite                                                                                                                                                 | Grund                                                                                                                                                                           |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| URLs                                                 | Hash-Router `/#!<state>`, `?page=<state>`                                                           | saubere Pfade (`/wahlometer/`, `/ueber-uns/` …), Startseite `/` = State `home`                                                                                  | statisches Hosting; alte Links (auch `#!<state>#<anker>`, `?_escaped_fragment_=<state>`, `/democracy/`) werden im Browser sofort umgeleitet, unbekannte States wie live auf `/` |
| CSS-Auslieferung                                     | ein minifiziertes Bundle unter `/cache/…`                                                           | die Originaldateien einzeln unter `/css/…` in derselben Reihenfolge; leere Modul-Dateien (Kontakt, Nutzungsbedingungen, Datenschutz, Impressum, Blog) entfallen | nachvollziehbar und ohne Server-Cache; nur die `url()`-Pfade sind relativ zu `/css/` angepasst, damit sie unter einem basePath funktionieren                                    |
| Seitenwechsel                                        | jQuery lädt `#content` per AJAX nach                                                                | Next.js lädt die nächste Seite beim Klick, ohne Prefetch                                                                                                        | gleiche Wirkung; Prefetch abgeschaltet wie live                                                                                                                                 |
| Zwischenzustand beim Laden                           | das Template zeigt kurz vier aktive Menüpunkte und unveränderte Inhalte, bis `init_<state>()` läuft | der Endzustand nach dem Init wird direkt ausgeliefert                                                                                                           | kein sichtbarer Unterschied nach dem Laden                                                                                                                                      |
| Anker auf einer anderen Seite (`/engineering/#help`) | nach dem Laden animiertes Scrollen (600 ms)                                                         | Sprung zum Anker                                                                                                                                                | Next.js/Browser-Standard; Anker auf derselben Seite scrollen wie live animiert                                                                                                  |
| Head                                                 | Reihenfolge der Tags aus dem Template                                                               | gleiche Tags und Werte, andere Reihenfolge; zusätzlich `rel="preload"` für Bilder und Skripte                                                                   | Next.js/React; ohne sichtbare Wirkung                                                                                                                                           |
| 404                                                  | Apache-Fehlerseite ohne Website-Rahmen                                                              | Seite „404“ im Website-Rahmen                                                                                                                                   | statisches Hosting braucht eine eigene 404-Seite                                                                                                                                |
| Smooth-Scroll aus `default_page.js` (`$(".scroll")`) | bindet beim Laden an keine Elemente (Inhalte kommen später, kein Template nutzt die Klasse)         | nicht portiert                                                                                                                                                  | wirkungslos auf live                                                                                                                                                            |

## Behobene Fehler

| Ort                                               | Fehler live                                                                                                                                                                                         | Behebung                                             |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Scroll-Pfeil im Header (Startseite, Wahl-O-Meter) | Der Link hat `href="#"` ohne `preventDefault`. Der Hash-Router lädt daraufhin die Startseite: Auf dem Wahl-O-Meter landet man auf „DEMOCRACY“, auf der Startseite springt die Seite kurz nach oben. | Klick scrollt nur noch (750 ms) zum ersten `#about`. |
| Presse-Logos (Startseite, Wahl-O-Meter)           | `target=”_blank”` mit typografischen Anführungszeichen: alle Logos öffnen sich in einem gemeinsamen Fenster namens `”_blank”`                                                                       | `target="_blank"`                                    |
| YouTube-Vorschaubild                              | Das jQuery-Plugin lädt `http://i.ytimg.com/…` (gemischter Inhalt)                                                                                                                                   | `https://i.ytimg.com/…`                              |
| Bilder ohne `alt`                                 | Hintergrundlogo, Telefon-Screenshots, Icons ohne `alt`                                                                                                                                              | `alt=""` (dekorativ), ohne sichtbare Änderung        |

## Inhalte und Links

| Thema                       | Live                                               | Statische Seite                                                                                        | Grund                                                                                                                                                                                                                                                                                   |
| --------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| APK/AAB-Download            | `/files/download/democracy-app.{apk,aab}` von 2024 | `https://github.com/demokratie-live/democracy-client/releases/latest/download/democracy-app.{apk,aab}` | keine großen Binärdateien im Website-Repo. Solange das neueste Release von democracy-client v1.5.0 (2021) ist, liefert der Link eine ältere App als live; dafür ist ein neues Release mit den Dateien von 2024 nötig. Die Beschriftung „APK (v1.5.10)“ bzw. „(v1.5.9)“ bleibt wie live. |
| Symbol-Icons (Wahl-O-Meter) | `<img src="….svg" onerror="…png">`                 | nur SVG                                                                                                | jeder aktuelle Browser zeigt SVG; der PNG-Fallback greift nie                                                                                                                                                                                                                           |
| Social-Media im Footer      | Instagram und Telegram als Font-Awesome-Icons      | wie live                                                                                               | das PHP-Repo ist hier älter (Instagram als Bild, ohne Telegram)                                                                                                                                                                                                                         |
