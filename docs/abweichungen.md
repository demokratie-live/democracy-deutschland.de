# Abweichungen vom Original

Die statische Seite ist ein 1:1-Port von [democracy-deutschland.de](https://democracy-deutschland.de/). Hier steht jede bewusste Abweichung und jeder behobene Fehler mit Begründung, außerdem die Restabweichungen aus dem Screenshot-Vergleich (`pnpm compare`). Maßstab ist die Live-Seite, nicht das PHP-Repo.

## Rahmen und Technik

| Thema                                                | Live                                                                                                | Statische Seite                                                                                                                                                 | Grund                                                                                                                                                                           |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| URLs                                                 | Hash-Router `/#!<state>`, `?page=<state>`                                                           | saubere Pfade (`/wahlometer/`, `/ueber-uns/` …), Startseite `/` = State `home`                                                                                  | statisches Hosting; alte Links (auch `#!<state>#<anker>`, `?_escaped_fragment_=<state>`, `/democracy/`) werden im Browser sofort umgeleitet, unbekannte States wie live auf `/` |
| CSS-Auslieferung                                     | ein minifiziertes Bundle unter `/cache/…`                                                           | die Originaldateien einzeln unter `/css/…` in derselben Reihenfolge; leere Modul-Dateien (Kontakt, Nutzungsbedingungen, Datenschutz, Impressum, Blog) entfallen | nachvollziehbar und ohne Server-Cache; nur die `url()`-Pfade sind relativ zu `/css/` angepasst, damit sie unter einem basePath funktionieren                                    |
| Seitenwechsel                                        | jQuery lädt `#content` per AJAX nach                                                                | Next.js lädt die nächste Seite beim Klick, ohne Prefetch                                                                                                        | gleiche Wirkung; Prefetch abgeschaltet wie live                                                                                                                                 |
| Zwischenzustand beim Laden                           | das Template zeigt kurz vier aktive Menüpunkte und unveränderte Inhalte, bis `init_<state>()` läuft | der Endzustand nach dem Init wird direkt ausgeliefert                                                                                                           | kein sichtbarer Unterschied nach dem Laden                                                                                                                                      |
| Anker auf einer anderen Seite (`/engineering/#help`) | nach dem Laden animiertes Scrollen (600 ms)                                                         | Sprung zum Anker                                                                                                                                                | Next.js/Browser-Standard; Anker auf derselben Seite scrollen wie live animiert                                                                                                  |
| Head                                                 | Reihenfolge der Tags aus dem Template                                                               | gleiche Tags und Werte, andere Reihenfolge; zusätzlich `rel="preload"` für Bilder und Skripte                                                                   | Next.js/React; ohne sichtbare Wirkung                                                                                                                                           |
| 404                                                  | Apache-Fehlerseite ohne Website-Rahmen                                                              | Seite „404“ im Website-Rahmen                                                                                                                                   | statisches Hosting braucht eine eigene 404-Seite                                                                                                                                |
| Smooth-Scroll aus `default_page.js` (`$(".scroll")`) | bindet beim Laden an keine Elemente (Inhalte kommen später, kein Template nutzt die Klasse)         | nicht portiert                                                                                                                                                  | wirkungslos auf live                                                                                                                                                            |

## Behobene Fehler

| Ort                                               | Fehler live                                                                                                                                                                                                                                                                                                                                                                   | Behebung                                                                                                                                                                                                               |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Scroll-Pfeil im Header (Startseite, Wahl-O-Meter) | Der Link hat `href="#"` ohne `preventDefault`. Der Hash-Router lädt daraufhin die Startseite: Auf dem Wahl-O-Meter landet man auf „DEMOCRACY“, auf der Startseite springt die Seite kurz nach oben.                                                                                                                                                                           | Klick scrollt nur noch (750 ms) zum ersten `#about`.                                                                                                                                                                   |
| Presse-Logos (Startseite, Wahl-O-Meter)           | `target=”_blank”` mit typografischen Anführungszeichen: alle Logos öffnen sich in einem gemeinsamen Fenster namens `”_blank”`                                                                                                                                                                                                                                                 | `target="_blank"`                                                                                                                                                                                                      |
| YouTube-Vorschaubild                              | Das jQuery-Plugin lädt `http://i.ytimg.com/…` (gemischter Inhalt)                                                                                                                                                                                                                                                                                                             | `https://i.ytimg.com/…`                                                                                                                                                                                                |
| Patenschafts-Modal (Spenden)                      | Verlässt man die Seite bei offenem Modal (Zurück-Taste), bleiben Backdrop und `body.modal-open` stehen: Die Folgeseite ist abgedunkelt und scrollt nicht mehr.                                                                                                                                                                                                                | Beim Verlassen der Seite werden Backdrop, Body-Klasse und Scrollbar-Ausgleich entfernt.                                                                                                                                |
| Team-Hover (Über uns)                             | Beim Zeigen auf Marius Krüger und Manuel Ruck wechselt das Foto auf `Marius2.png` bzw. `Manu2.png`. Beide Dateien wurden 2021 gelöscht, der Server antwortet mit einer JSON-Fehlermeldung: Die Karte zeigt ein kaputtes Bild und schrumpft auf die Link-Zeile.                                                                                                                | Das Foto bleibt stehen, nur Text und Kontakt-Links tauschen (wie bei Elisa Menne). Ein zweites Foto lässt sich in `content/team/team.yaml` als `imgHover` eintragen; `pnpm validate-content` prüft, dass es existiert. |
| FAQ-Kategorie-Menü                                | Ist die erste sichtbare Frage beim Menü-Klick schon offen (nach dem Laden „ALLE“ oder „DATENSCHUTZ“, zweiter Klick auf dieselbe Kategorie), klappt sie zu und die nächste Frage öffnet sich. `init_faq()` ruft `collapse('show')` für `.panel-faq:visible .collapse:first`, während die erste Frage noch zuklappt und deshalb die Klasse `collapsing` statt `collapse` trägt. | Nach jedem Menü-Klick ist die erste sichtbare Frage offen, alle anderen klappen zu (Absicht des Codes). Auf allen anderen Wegen verhält sich das Menü wie live.                                                        |
| Presse: Alt-Text „MDR Doku“                       | Der Titel enthält ASCII-Anführungszeichen (`"Mehr Bürger an die Macht?"`); das `alt`-Attribut endet beim ersten davon, der Rest wird zu ungültigen Attributen (`mehr`, `bürger` …).                                                                                                                                                                                           | Vollständiger Titel als `alt`. Sichtbar wäre der Unterschied nur, wenn das Bild fehlt.                                                                                                                                 |
| Bilder ohne `alt`                                 | Hintergrundlogo, Telefon-Screenshots, Icons ohne `alt`                                                                                                                                                                                                                                                                                                                        | `alt=""` (dekorativ), ohne sichtbare Änderung                                                                                                                                                                          |

## Spenden (`/spenden/`) und Spenden-JSON

| Thema                                                       | Live                                                                                      | Statische Seite                                 | Grund                                                                                                                             |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `querytime` im Spenden-JSON                                 | Laufzeit des PHP-Aufrufs, z.B. `0.01362`                                                  | `0`                                             | eine statische Datei hat keine Laufzeit; der Typ (Zahl) bleibt, die App wertet das Feld nicht aus                                 |
| Content-Type von `/api.php`                                 | `application/json`                                                                        | auf GitHub Pages `application/x-httpd-php`      | statisches Hosting bestimmt den Typ aus der Endung; die App parst die Datei trotzdem (geprüft, siehe `docs/server-funktionen.md`) |
| andere `api.php?call=…`                                     | je Aufruf eigene Antwort                                                                  | immer der Spendenstand                          | ein statischer Host ignoriert den Query-String; die übrigen Aufrufe stehen in `docs/server-funktionen.md`                         |
| „Jetzt Pate werden“, „Einmalig Spenden“ (`#!donate#donate`) | der Hash-Router lädt den Seiteninhalt per AJAX neu, dann scrollt er animiert zu `#donate` | scrollt nur, gleiche Animation und Zielposition | kein Nachladen nötig; der Inhalt ist derselbe                                                                                     |
| Fortschrittsbalken der Posten (`updateProgress`)            | einmal beim Einfügen des Inhalts und bei jedem Resize                                     | zusätzlich, wenn die Webfonts geladen sind      | live kommt der Inhalt erst nach dem Laden der Schriften, die statische Seite kann früher hydrieren; Endzustand wie live           |
| `onresize="updateProgress()"` an den Tabellenzeilen         | Attribut vorhanden, ohne Wirkung (Zeilen bekommen kein `resize`)                          | entfällt                                        | React rendert keine Event-Handler als Text-Attribut; das Neuberechnen beim Resize übernimmt wie live der `window`-Listener        |
